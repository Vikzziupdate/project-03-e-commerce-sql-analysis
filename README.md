# E-Commerce SQL Data Analysis

## Project Overview
This project uses MySQL to analyze e-commerce order data and answer practical business questions about product performance, order values, order statuses, payment methods, referral sources, and monthly trends.

## Objectives
- Validate the structure and quality of the dataset.
- Retrieve and filter records using SQL.
- Summarize data with aggregate functions and GROUP BY.
- Analyze monthly patterns and product performance.
- Apply CASE statements, subqueries, CTEs, and window functions.
- Communicate findings and analytical limitations.

## Tools
- MySQL
- MySQL Workbench
- SQL
- GitHub

## SQL Skills Demonstrated
SELECT, WHERE, DISTINCT, ORDER BY, GROUP BY, HAVING, COUNT, SUM, AVG, MIN, MAX, CASE, subqueries, CTEs, and RANK.

## Key Deliverables
- SQL scripts organized by analysis stage
- Data-quality checks
- Business analysis queries
- Advanced SQL analysis
- Screenshots of query results
- Findings report

## Data Privacy
The original dataset contains customer-related information. Raw customer records and sensitive identifiers are excluded from this public repository. The project documentation and screenshots are prepared to avoid disclosing personal information.

## Limitations
Recorded order value is not necessarily realized revenue. Conclusions about revenue, returns, cancellations, and marketing performance require validated business definitions and appropriate transaction data.

## Learning Outcome
This project demonstrates my ability to use SQL to investigate data quality, summarize business records, compare categories, analyze trends, and communicate data-driven findings.
